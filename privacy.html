Ducktown Pin Scheduler privacy policy

Effective October 22, 2026

Ducktown Pin Scheduler is a private tool that Ducktown Graphics, an independent digital art shop on Etsy, uses to publish its own artwork to its own Pinterest account. It is not offered to the public, and nobody else signs in to it.

What the tool accesses

  • The Ducktown Graphics Pinterest account's boards (names and IDs), so each Pin goes to the right board.
  • Pins the tool creates on that account: their images or videos, titles, descriptions and links.
  • Basic profile details of the signed-in account, to confirm it is the Ducktown Graphics account.

The tool does not read, collect or store information about any other Pinterest user, and it does not access followers, messages or ads.

How information is stored

The access token Pinterest issues after sign-in is stored only on the shop owner's own computer, in a private settings folder. The app ID and secret are kept in that computer's user environment settings. Nothing is uploaded to any other server or shared with third parties.

How information is used

Information is used only to publish and manage Ducktown Graphics Pins on a posting schedule the shop owner sets. It is not sold, rented, used for advertising, or combined with other data. The tool uses no cookies and no analytics.

Removing access

Access can be revoked at any time from Pinterest under Settings, then Apps. Revoking access makes the stored token stop working, and the token file is deleted from the computer.

Changes

If the tool starts using any other information, this page will be updated and the effective date will change.

Contact

Questions about this policy can be sent through the Ducktown Graphics Etsy shop: etsy.com/shop/DucktownGraphics.
